# Nmap Labs

This repository contains my hands-on Nmap practice completed while learning cybersecurity and ethical hacking.

## Objective

- Learn how Nmap works.
- Practice network scanning.
- Understand ports and services.

## Tools Used

- Kali Linux
- Nmap
- VirtualBox
- Windows VM

## Commands Practiced

### Scan localhost

```bash
nmap 127.0.0.1
```

Scans the local machine.

### Detect service versions

```bash
nmap -sV 127.0.0.1
```

Detects service versions.

## What I Learned

- Open vs. closed ports
- Loopback address (127.0.0.1)
- Basic network scanning
